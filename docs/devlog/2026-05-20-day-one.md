# Day one — 2026-05-20

First push to `main`. Setting the project up as the fourth instance of the **Shareable CAD** pattern (see [`SHAREABLE-CAD.md`](../../SHAREABLE-CAD.md)), with OpenSCAD as source-of-truth instead of Onshape. The earlier three projects (gear card, Pounce-a-Pult, vault) all use Onshape; `open-studs` is the first time the pattern gets tested with a code-first parametric tool.

## What landed

- **Vertical-slice geometry.** `bracelet.scad` + `sizing_test.scad`, every stud working (7 designs), every pattern working except `cluster` and `gradient_size` (signatures locked, bodies stubbed), 2 of 5 latches working (`buckle`, `friction_overlap`), the other 3 stubbed. The README's exact Quick Start example (`long_spike` + `staggered` + `buckle` + `integral`) renders end-to-end.
- **Python kernel skeleton.** `src/open_studs/params.py` mirrors every default. `studslab inspect` works against any `.scad` file (regex-based, no OpenSCAD dependency). `explainers build` generates four markdown pages under `docs/explainers/` from the parameter mirror.
- **Pattern docs.** `SHAREABLE-CAD.md` adapted from the pycon2026 version with an "OpenSCAD vs Onshape variant" comparison table. `CONTRIBUTING.md` carries the module-signature contract.
- **Dual licensing** (MIT for code, CC BY 4.0 for designs) in place.

## Open design questions to revisit

These were left at reasonable defaults in Push 1 but are worth iterating on:

1. **Pyramid construction approach.** Currently `cylinder($fn=4)` because `tip_radius` drops in cleanly as the top radius. Alternatives: explicit `polyhedron` (more control, no fillet); `hull()` over a square base and a point (clean, harder to flatten); `minkowski` for true fillets (slow). See the LEARNING-MODE comment in `studs/pyramid.scad`.
2. **Buckle adjustability granularity.** Currently 5 holes at 5 mm = 20 mm of adjustability. Goth wants fewer/wider; festival wants more/tighter. See `latches/buckle.scad`.
3. **Single-row spacing strategy.** Currently auto-fits to the band length so studs sit evenly with the latch margin respected. Alternative: fixed mm spacing, accept the leftover gap. See `patterns/single_row.scad`.
